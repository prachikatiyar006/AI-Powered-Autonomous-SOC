# AI-Powered Autonomous SOC & Intelligent Incident Response System

## Project Overview
This project aims to develop an AI-powered Security Operations Center (SOC) that monitors security logs, detects suspicious activities, analyses potential cyber threats, and recommends automated incident response actions.

## Objectives
- Monitor security events and logs.
- Detect suspicious login activities.
- Identify potential cyberattacks.
- Classify threats based on severity.
- Use AI to analyse security incidents.
- Automate safe incident response actions.
- Display security information through a dashboard.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Streamlit
- SQLite
- AI/LLM API

## Project Modules
1. Security Log Collection
2. Threat Detection
3. Machine Learning Analysis
4. AI Incident Analysis
5. Automated Incident Response
6. SOC Dashboard
