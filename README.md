# AI-Powered Autonomous SOC & Intelligent Incident Response System

## Project Overview
This project aims to develop an AI-powered Security Operations Center (SOC) that monitors security logs, detects suspicious activities, analyses potential cyber threats, and recommends automated incident response actions.

## Objectives
- Monitor security events and logs.
- Detect suspicious login activities.
- Identify potential cyberattacks.
- Classify threats based on severity.
- Use AI to analyse security incidents.
- Automate safe incident response actions.
- Display security information through a dashboard.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Streamlit
- SQLite
- AI/LLM API

## Project Modules

1. Security Log Collection
2. Threat Detection
3. Machine Learning Analysis
4. AI Incident Analysis
5. Automated Incident Response
6. SOC Dashboard

## Key Features

- Security Log Monitoring: Collect and display security events.
- Threat Detection: Identify suspicious login attempts and activities.
- Threat Classification: Categorize threats based on severity (High, Medium, Low).
- Attack Analytics: Visualize threat patterns and security statistics.
- AI Incident Analysis: Generate insights and analysis of detected threats.
- Incident Management: Track and manage security incidents.
- Incident Response: Provide recommended actions for detected threats.
- Security Reports: Generate and download security reports.
- Interactive SOC Dashboard: Monitor security information through a Streamlit interface.

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/prachikatiyar006/AI-Powered-Autonomous-SOC.git
cd AI-Powered-Autonomous-SOC
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python -m streamlit run app.py
```

### 4. Open in Browser

Open the local URL displayed in your terminal:

```text
http://localhost:8501
```
